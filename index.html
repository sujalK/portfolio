Learning product

QBASIC — The Learning App

I designed, wrote and shipped an Android app for school students and first-time programmers. It used QBASIC to make core programming concepts approachable through structured, step-by-step learning material.

  1. May 2, 2016
    Initial Android launch

    The first public release made the learning material available as a self-paced mobile app.

  2. May 12, 2017
    Follow-up release

    A second release continued the app's focus on helping beginners learn QBASIC and programming fundamentals.

  3. 2017–2019
    Top-ranked app

    While available on the Play Store, it ranked at the top for “QBASIC” searches and became the leading, most-downloaded dedicated QBASIC learning app in its niche.

  4. 2021
    Removed from Google Play

    The app was taken down after I could no longer update it to meet Google’s policy changes. I had built it while still in school and later lost the signing license file, so a compliant update was no longer possible. The learning material remains available through other app stores.

sujal/validation: PHP validation library
Open source · MIT

A PHP validation library built around reusable Rule classes. You build an immutable Schema of Fields, hand it to a ValidationEngine, and get pass/fail results with messages instead of a long chain of if statements.

  • Built for PHP 8.2+, no framework required.
  • Rules like Required, Email, Min/Max, Confirmed, Nested paths, and wildcards (e.g. items.*.email).
  • Designed around SOLID boundaries so new rules are new classes, not engine changes.
  • Covered with PHPUnit tests (composer test).

Stack: PHP 8.2+, Composer, PHPUnit
